# ライアーズ・バッティング（Liar's Batting）

数字当て野球のルールに、嘘・信頼と疑い・ヒーロー能力を加えた心理戦ゲームです。AIと対戦したり、オンラインでランダム対戦やフレンド対戦を楽しめます。

この文書は、Unityを初めて使うチームメンバーでも実行できるように、導入から操作までを説明しています。上から順番に進めてください。

---

## 1. 事前インストール（初回のみ）

### 1-1. Git
- https://git-scm.com/downloads からインストールしてください（基本設定のままNextを押して進められます）。

### 1-2. Unity Hub
- https://unity.com/download からUnity Hubをインストールしてください。
- Unity HubはUnity本体ではなく、複数バージョンのUnity Editorを管理するランチャーです。実際のEditorは次の手順でHubからインストールします。

### 1-3. Unity Editor 6000.6.0f1のインストール
このプロジェクトは**正確に6000.6.0f1**で作成されています。別のバージョンではプロジェクトが開けなかったり、予期しないエラーが発生したりする可能性があるため、同じバージョンを使用してください。

1. Unity Hubを起動し、左メニューの**Installs**タブから**Install Editor**を選択します。
2. 一覧に6000.6.0f1がない場合は、右上の**Archive**（または「別のバージョンを探す」）を開いて検索します。`https://unity.com/releases/editor/whats-new/6000.6.0` の「Unity Hubでインストール」リンクからもHubに認識させられます。
3. Modulesの選択画面では、最低限次を選択します。
   - **Microsoft Visual Studio Community**（IDEがない場合。コードエディターとコンパイラーです）
   - OSに合ったビルドターゲット（Windowsでは追加選択なしでもEditorの実行とテストができます）
4. インストールが完了するまで待ちます。容量が大きいため、しばらく時間がかかります。

### 1-4. IDE（コードエディター）
- 手順3でVisual Studio Communityを一緒にインストールした場合、別途インストールする必要はありません。
- RiderやVS Codeなど、別のエディターを使う場合も問題ありません。

## 2. プロジェクトの取得（クローン）

任意のフォルダーでターミナル（Git Bash、PowerShellなど）を開きます。

```bash
git clone https://github.com/Rokmc1292/Game_project.git
```

完了すると`Game_project`フォルダーが作成されます。

> すでにクローン済みで、チームメンバーが追加した最新変更だけを取得したい場合：
>
> ```bash
> git pull
> ```

---

## 3. Unity Hubでプロジェクトを開く

1. Unity Hubを起動し、左メニューの**Projects**タブから**Add**（または**Open**）を選択します。
2. クローンした`Game_project`フォルダーを選択します。
3. プロジェクトが一覧に追加されたらクリックして開きます。
   - Hubに「このプロジェクトには6000.6.0f1が必要です」と表示された場合は、手順1-3でインストールしたバージョンを選択してください。
4. 初回起動には数分かかります。Unityがパッケージをダウンロードしてスクリプトをコンパイルするため、右下の進行バーが完了するまで待ってください。
5. Editorが開いたら、下部の**Console**タブに赤いエラーがないことを確認します。黄色い警告は無視できます。

---

## 4. 実行してみる（Play）

このプロジェクトではSceneにオブジェクトを事前配置していません。ゲームのUIとロジックは`GameBootstrap.cs`が実行時に自動生成するため、どのSceneを開いても動作します。

1. 上部の**Project**ウィンドウで`Assets/Scenes/SampleScene.unity`をダブルクリックして開きます。すでに開いている場合は不要です。
2. 画面上部中央の**Play**ボタンをクリックします。
3. ニックネーム入力画面が表示されれば正常です。任意のニックネームを入力して進めてください。
4. メインメニューで**AI対戦**を選ぶと、ネットワークなしで一人プレイできます。

---

## 5. オンライン対戦（ランダム対戦・フレンド対戦）のテスト — ParrelSync

オンライン対戦には相手のクライアントが必要です。チームメンバーとそれぞれ実行することもできますが、PC1台だけでもテストできるように、`ParrelSync`というEditor拡張をプロジェクトに導入しています。

1. Unity Editor上部メニューの**ParrelSync → Clones Manager**をクリックします。
   - メニューが表示されない場合は、まずConsoleにエラーがないか確認してください。
2. **Create new clone**をクリックすると、プロジェクトの隣に`Game_project_clone`フォルダーが自動作成されます。
3. クローン作成後、**Open in New Editor**をクリックして2つ目のUnity Editorを開きます。
4. 元のEditorとクローンの両方で**Play**をクリックし、それぞれ異なるニックネームで接続します。クローンのニックネーム保存先は自動的に分離されます。
5. 一方で「ランダム対戦」を選び、もう一方でも選ぶとマッチングして対戦が始まります。「フレンド対戦」では相手のニックネームが必要です。

> ParrelSyncのクローンフォルダー（`Game_project_clone`）はGitリポジトリの外に作られるため、自由に作成・削除できます。

## 6. オンライン対戦 — Firebase設定

### 6-1. 仕組み
オンライン対戦は、Googleの**Firebase Firestore**を通して2つのクライアントがターンと状態を共有します。このプロジェクトは専用SDKを使わず、REST API（HTTPリクエスト）で直接通信するため、SDKの追加インストールやFirebaseコンソールへの登録は不要です。

- 接続情報（プロジェクトID、APIキー）は`Assets/_Project/Scripts/Network/FirebaseConfig.cs`にあり、リポジトリに含まれています。
- クローンすると全員が同じFirestoreプロジェクト（`liarsbatting`）を共有するため、別々のPCからでもマッチングできます。
- `matches/{matchId}`にはターン情報、相手に伝えた結果（嘘の場合もあります）、公開された数字だけが記録されます。各プレイヤーの本当の4桁パスワードはサーバーに送信されません。判定は各クライアントで行い、サーバーには結果だけを書き込みます。

### 6-2. APIキーがコードにあるのは問題ないか
`FirebaseConfig.cs`の`ApiKey`はFirebase Web APIキーであり、サーバーの秘密鍵ではありません。Firebase公式ドキュメントでもクライアントアプリへの組み込みを前提としており、セキュリティはキーではなく**Firestore Security Rules**で管理します。

- リポジトリをpublicにしたり、別の場所で共有したりする場合は、Security Rulesをさらに厳しくする必要があります。
- Firebase Admin SDKのサービスアカウントJSONなど、実際のサービス秘密鍵は絶対にコミットしないでください。将来サーバー機能を追加する場合は`.gitignore`に登録し、チーム内で別途管理してください。

### 6-3. チームメンバーが行うこと
**ありません。** クローン、Unity Hubで起動、Playの順に進めれば、オンライン対戦まで動作します。Firebaseコンソールへの登録やプロジェクト作成、キー発行は不要です。

## 7. プロジェクト構成

```text
Assets/_Project/Scripts/
├─ Core/          ゲームルールのデータ（数字判定、状態など）を扱う純粋なC#
├─ AI/            AI相手のロジック（推理アルゴリズム、ヒーロー能力の判断）
├─ Network/       Firestore通信、オンライン対戦、ターンプロトコル
└─ Presentation/  画面UI全体（コードで生成、SceneやPrefabは不要）
```

バグ修正や機能追加では、画面全体の流れを担当する`Presentation/GameBootstrap.cs`を主に確認します。

---

## 8. 共同作業時の注意（Git）

- **`Library/`、`Logs/`、`UserSettings/`、`*.csproj`、`*.sln`はコミットしないでください。** `.gitignore`に登録済みです。Unityが生成するキャッシュや自動生成ファイルなので、コミットしても意味がなく容量だけ増えます。
- SceneとPrefabはテキスト（YAML）形式（`Force Text`）で保存されるためdiffを確認できます。ただし同じSceneやPrefabを複数人が同時編集すると衝突しやすいです。このプロジェクトはSceneをほとんど使いませんが、`.meta`ファイルはスクリプトと一緒に必ずコミットしてください。
- コミット前に、Unity Consoleに赤いエラーがないことを確認してください。

## 9. よくある問題（トラブルシューティング）

**Q. Unity Hubで「バージョンがありません」と表示される。**

→ 手順1-3に従い、6000.6.0f1を正確にインストールしてください。

**Q. 初回起動時にConsoleへ大量のエラーが表示される。**

→ パッケージのインストールやコンパイルが完了していない可能性があります。進行バーが終わるまで待ってから確認してください。それでも残る場合は、上部メニューの`Assets → Reimport All`を試してください。

**Q. 上部メニューに`ParrelSync`が表示されない。**

→ コンパイルが終わっていないか、エラーのためスクリプトがコンパイルされていません。先にエラーを解決してください。

**Q. 履歴エリアをマウスホイールでスクロールできない。**

→ スクロールしたいエリアの上にカーソルを置いてください。New Input Systemで直接ホイール入力を読んでいるため、エリア外では反応しません。

**Q. ランダム対戦が成立しない。**

→ 相手側（チームメンバーのPCまたはParrelSyncクローン）も同じタイミングで「ランダム対戦」を選び、待機している必要があります。片方だけ起動している場合、相手を待ち続けるのが正常です。

## 10. プレイの流れ

ニックネーム設定（初回のみ） → メインメニュー（AI対戦 / ランダム対戦 / フレンド対戦） → ヒーロー選択 → 4桁パスワード設定 → 対戦開始 → 毎ターン推理 → 信頼または疑いの判断 → 勝敗決定
