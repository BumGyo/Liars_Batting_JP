# ライアーズ・バッティング (Liar's Batting)

数字当て（ヌメロン/野球盤）のルールに「嘘（ブラフ）」、「信頼・ダウト（疑う）」、「ヒーロー固有能力」を掛け合わせた心理戦対戦ゲームです。AI対戦のほか、オンラインでのランダムマッチやフレンドマッチに対応しています。

このドキュメントは、**Unityを初めて触るチームメンバー**でも手順通りに進めれば実行まで到達できるように詳しく記載しています。順番に進めてください。

---

## 1. 事前準備（初回のみ）

### 1-1. Git
- https://git-scm.com/downloads からインストール（基本設定のままNextを押して完了して問題ありません）

### 1-2. Unity Hub
- https://unity.com/download から Unity Hub をインストール
- Unity本体ではなく「複数バージョンのUnityエディターを管理するランチャー」です。実際のエディターは次のステップでHub内からインストールします。

### 1-3. Unity エディター 6000.6.0f1 のインストール
このプロジェクトは**正確に 6000.6.0f1** バージョンで作成されています。バージョンが異なるとプロジェクトが開かなかったり予期せぬエラーが発生する可能性があるため、必ず同じバージョンに合わせてください。

1. Unity Hub を起動 → 左メニューの **Installs** タブ → **Install Editor**
2. 一覧に 6000.6.0f1 が見当たらない場合は、右上の **Archive**（または「他のバージョンを探す」）から検索:
   `https://unity.com/releases/editor/whats-new/6000.6.0` ページの「Unity Hubでインストール」リンクをクリックしてもHubが自動認識します。
3. モジュール（Modules）選択画面では、最低限以下にチェックを入れてください:
   - **Microsoft Visual Studio Community**（IDEをまだ持っていない場合はチェック — コードエディター兼コンパイラ）
   - ご使用のOSに合わせたビルドターゲット（Windowsの場合、特別な追加チェックを行わなくてもエディターの実行・テストは可能です）
4. インストールが完了するまで待機（容量が大きいため多少時間がかかります）

### 1-4. IDE（コードエディター）
- 上記3でVisual Studio Communityを一緒にインストールした場合は、別途のインストールは不要です。
- すでに他のエディター（Rider, VS Codeなど）を使用したい場合は、そちらを使用しても問題ありません。

## 2. プロジェクトの取得（クローン）

任意のフォルダーでターミナル（Git Bash, PowerShellなど）を開き、以下を実行します:

```bash
git clone https://github.com/BumGyo/Liars_Batting_JP.git
```

完了すると `Liars_Batting_JP`（またはクローンしたフォルダー）が作成されます。

> すでにクローン済みの状態で最新の変更を取得したい場合:
> ```bash
> git pull
> ```

## 3. Unity Hubでプロジェクトを開く

1. Unity Hub を起動 → 左メニューの **Projects** タブ → **Add**（または「Open」）ボタン
2. クローンしたプロジェクトフォルダーを選択
3. 一覧にプロジェクトが追加されたら、クリックして開く
   - Hubが「このプロジェクトには 6000.6.0f1 が必要です」と表示した場合は、1-3でインストールしたバージョンを選択してください。
4. **初回起動時は数分程度かかります。** Unityがパッケージをダウンロードし、すべてのスクリプトをコンパイルしているため、ステータスバー（右下の進捗バー）が完了するまでお待ちください。
5. 開いたらUnityエディター画面が表示され、下部の **Console** タブに赤いエラーが出ていないことを確認します（黄色の警告は無視して構いません）。

---

## 4. 実行してみる (Play)

このプロジェクトは、シーン（Scene）上にあらかじめオブジェクトを配置していません。ゲームUIおよびロジックのすべてが `GameBootstrap.cs` コードから実行時に動的生成されるため、**どのシーンを開いていても動作します。**

1. 上部の **Project** ウィンドウから `Assets/Scenes/SampleScene.unity` をダブルクリックして開きます（すでに開いている場合は省略）
2. 画面上部中央の ▶ **Playボタン** をクリック
3. ニックネーム入力画面が表示されれば正常に起動しています。任意のニックネームを入力して進めてみてください。
4. メインメニューで **AIマッチング** をクリックすると、ネットワークなしですぐに1人プレイをテストできます。

---

## 5. オンラインマッチ（ランダム/フレンド）のテスト — ParrelSync

オンライン対戦は相手クライアントが必要です。チームメンバーと各自実行してテストすることもできますが、**PC1台だけで1人でもテストできる**よう、`ParrelSync` というエディター拡張機能がプロジェクトに導入されています。

1. Unityエディターの上部メニュー **ParrelSync → Clones Manager** をクリック
   - メニューが表示されない場合は、下部のConsoleにエラーがないか確認してください（コンパイルが終わっていないとメニューが生成されません）。
2. **Create new clone** をクリック → プロジェクトフォルダーの横にクローンフォルダーが自動生成されます。
3. クローンが作成されたら **Open in New Editor** をクリック → 2つ目のUnityエディターウィンドウが開きます。
4. 元のウィンドウとクローンウィンドウの**両方でPlay**ボタンを押すと、それぞれ別のニックネームで接続されます（クローン側はニックネーム保存先が自動で分離されています）。
5. 片方で「ランダムマッチ」を押し、もう片方でも「ランダムマッチ」を押すとマッチングして対戦が始まります。「フレンドマッチ」はお互いのニックネームを指定して招待します。

> ParrelSyncのクローンフォルダーはGitリポジトリの**外側**に生成されるため、Gitにコミットされる心配はありません。

## 6. オンラインマッチ — Firebase設定の仕組み

### 6-1. 動作原理
オンライン対戦（ランダム/フレンド）はGoogleの **Firebase Firestore** クラウドデータベースを介して、2つのクライアントが互いのターンや状態を同期する設計です。通常Firebaseは専用SDKを導入しますが、本プロジェクトは**ネイティブSDKなしでREST API（HTTPリクエスト）によって直接通信**しています。そのため、SDKの追加インストールやFirebaseコンソールへの登録は一切不要です。

- 接続情報（プロジェクトID、APIキー）は `Assets/_Project/Scripts/Network/FirebaseConfig.cs` に記載されており、リポジトリにコミットされています。
- クローンした時点で**同一のFirestoreプロジェクト（`liarsbatting`）を共有**します。そのため、別々のPCから実行しても互いにマッチング可能です。
- 送受信されるデータ: マッチドキュメント1つ（`matches/{matchId}`）にターン情報、相手に伝えた（嘘の可能性もある）結果、公開された桁の数字のみが記録されます。**各自の真の暗証番号4桁はサーバーへ送信されません** — 判定は各自のクライアント上でローカル計算し、サーバーには「結果」のみを書き込みます。

### 6-2. APIキーがコードに含まれている点について
`FirebaseConfig.cs` の `ApiKey` は、いわゆる **Firebase Web APIキー** であり、サーバーのシークレットキーとは異なります。Firebase公式ドキュメントでもこのキーはクライアントアプリに含まれる前提で設計されており、セキュリティはキーではなく **Firestoreセキュリティルール（Security Rules）** によって担保する仕様となっています。

### 6-3. セキュリティルール (`firestore.rules`)
リポジトリ直下の `firestore.rules` がFirestoreセキュリティルールです。**Firebase Console → Firestore Database → ルール（Rules）タブ** に貼り付けて **公開（Publish）** することで適用されます。

- ゲームが使用する5つのコレクション（`players`, `matches`, `matchQueue`, `invites`, `matchPresence`）のみアクセスを許可し、それ以外のパスは遮断しています。
- 各ドキュメントにはゲームが実際に使用するフィールドのみ、指定の型・サイズでのみ保存可能です。
- 戦績は1回の書き込みにつき1勝または1敗のみ増加可能で、レベルが下がることはありません。

### 6-4. チームメンバーが事前に行う作業
**ありません。** クローン → Unity Hubで開く → Playボタンを押すだけでオンラインマッチングまで動作します。Firebaseコンソールへの登録やプロジェクト作成などの手順は不要です。

## 7. プロジェクト構成の概要

```
Assets/_Project/Scripts/
├─ Core/          ゲームルール・判定ロジック（数字当て判定、ゲーム状態など）— UnityEngine非依存の純粋なC#
├─ AI/            AI対戦相手ロジック（推理アルゴリズム、ヒーロー能力使用判断）
├─ Network/       Firestore通信、オンラインマッチング/ターンプロトコル
└─ Presentation/  画面UI・アニメーション全般（すべてコードによる動的生成、シーン/プレハブなし）
```

バグ修正や機能追加の際は、画面遷移および全体の進行フローを統括する `Presentation/GameBootstrap.cs` を参照してください。

---

## 8. 協業・開発時の注意事項 (Git)

- **`Library/`, `Logs/`, `UserSettings/`, `*.csproj`, `*.sln` 等のフォルダー/ファイルはコミットしないでください。** すでに `.gitignore` に指定されています。
- シーンやプレハブの競合を避けるため、本プロジェクトではUIをすべてコード（`UiFactory`）で構築しています。
- 新しいスクリプトを追加した際は、Unityが自動生成する `.meta` ファイルも必ず一緒にコミットしてください。

## 9. トラブルシューティング

**Q. Unity Hubでプロジェクトを開こうとすると「バージョンがない」と表示される。**
→ 1-3の手順に従い、6000.6.0f1をインストールしてください。

**Q. 初回起動時にConsoleにエラーが大量に出る。**
→ バックグラウンドでのパッケージダウンロードやコンパイルが完了していない可能性があります。進捗バーが完了するまでお待ちいただき、解消しない場合は上部メニュー `Assets → Reimport All` を実行してください。

**Q. 上部メニューに `ParrelSync` が表示されない。**
→ コンパイルが未完了かスクリプトにエラーがある状態です。エラーを解消するとメニューが表示されます。

**Q. 履歴エリアでマウスホイールによるスクロールが反応しない。**
→ スクロール対象のウィンドウ内にマウスポインタが入っている必要があります。New Input System上で直接ホイール入力を取得しているため、ポインタが枠外にあると反応しません。

**Q. ランダムマッチングがマッチしない。**
→ 対戦相手側（別PCまたはParrelSyncクローン）も同じタイミングで「ランダムマッチ」を押して待機している必要があります。

## 10. プレイの流れ

ニックネーム設定（初回のみ） → メインメニュー（AIマッチ / ランダムマッチ / フレンドマッチ） → ヒーロー選択 → 暗証番号（重複なし4桁）設定 → 対戦開始 → ターンごとの推理 → 信頼 / ダウト（疑う）判断 → 勝敗決定
